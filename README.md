# boilerplate-stencil

## Install

```bash
pnpm install
````

## Develop

```bash
pnpm start  
````

### Build

```bash
pnpm build
````

### Test

```bash
pnpm test
```

```

# Stencil
npm run build --workspace=@boilerplate-stencil/core
npm run build --workspace=@boilerplate-stencil/components


# Angular Adapter
npm run build:core --workspace=@boilerplate-stencil/angular
npm run build:component --workspace=@boilerplate-stencil/angular

# Playground starten
npm run start --workspace=@boilerplate-stencil/playground

```
